features:
  - title: One list, every format
    details: Deplug scans the standard plugin folders on Windows, macOS and Linux and groups what it finds by format. Filter VST2, VST3, AAX, AU and CLAP with one click, and open any plugin's folder.
    link: /using-deplug
    linkText: How scanning works
  - title: Trash, not delete
    details: Uninstalling moves the plugin to the system trash, so a wrong click is a restore away. On Windows it can create a System Restore point first, like Revo Uninstaller does.
    link: /safety-and-privacy
    linkText: Safety and privacy
  - title: Finds copied plugins too
    details: Plugins dragged into a folder by hand do not show up in any installer list. Add that folder as a custom scan folder and Deplug will find them.
    link: /custom-folders
    linkText: Custom folders
  - title: Installer or portable
    details: Install it the usual way, or unpack the portable build on a USB stick. A small portable.txt file next to the app keeps all of its data beside it.
